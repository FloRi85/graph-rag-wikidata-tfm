Graph-RAG on Wikidata — demonstration interface

Runs the four evaluated configurations on one question and shows each answer beside the retrieved context supplied to the model. Presets are illustrative reruns on the tuning split: they reproduce the evaluated question annotations, not frozen results.
Input
Up to 5 rate-paced LLM calls; uncached entities fetch live from Wikidata/Wikipedia — a run can take minutes.
